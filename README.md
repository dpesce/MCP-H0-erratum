# MCP H0 erratum

This repository hosts a preprint of the erratum to the Megamaser Cosmology Project (MCP) paper [The Megamaser Cosmology Project. XIII. Combined Hubble Constant Constraints](https://iopscience.iop.org/article/10.3847/2041-8213/ab75f0).  The erratum has been submitted to the journal for review.
